PROYECTO CLUB ABASTENSE

Archivos:
- index.html
- styles.css
- img/escudo.png

Cómo usarlo:
1. Abrí la carpeta en Visual Studio Code.
2. Abrí index.html en el navegador o con Live Server.
3. Reemplazá los bloques de color que dicen “Imagen del club”, “Fútbol”, etc. por imágenes reales.
4. Revisá dirección, teléfono, correo y textos antes de entregar.

Nota:
Los controles del hero son visuales. Para que el carrusel cambie de noticia de verdad hace falta JavaScript.

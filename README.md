# Sitio web Club Abastense

Sitio web desarrollado para el Club Atlético Abastense Argentino, una organización deportiva y social ubicada en la localidad de Abasto, partido de La Plata.

El club funciona como un espacio de encuentro para la comunidad y ofrece distintas actividades deportivas y recreativas para niños, jóvenes y adultos, entre ellas fútbol, vóley, baile, boxeo, gimnasio y bochas.

El sitio permite conocer la institución, consultar sus actividades y noticias, completar un formulario para solicitar información y acceder a los datos de contacto y ubicación del club.
